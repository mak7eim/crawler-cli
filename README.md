# crawler-cli

`crawler-cli` — CLI-приложение на Go для параллельного обхода HTML-страниц
в пределах домена стартового URL и сохранения найденного дерева страниц в JSON.

## Сборка

```bash
go build -o crawler-cli ./cmd/app
```

## Запуск

```bash
./crawler-cli \
  --urls https://example.com \
  --depth 1 \
  --timeout 2m \
  --request-timeout 10s \
  --output result.json \
  --log crawler.log
```

### Параметры


| Флаг            | По умолчанию | Описание                                                                                                        |
| ------------------- | ----------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `--urls`            | —                      | Стартовые URL через запятую. Обязательный параметр.                            |
| `--depth`           | `1`                     | Максимальная глубина обхода. Стартовая страница имеет глубину`0`. |
| `--timeout`         | `2m`                    | Общий timeout всего обхода.                                                                             |
| `--request-timeout` | `10s`                   | Timeout отдельного HTTP-запроса.                                                                       |
| `--output`          | `output.json`           | Путь к JSON-файлу с результатом.                                                                  |
| `--log`             | `crawler.log`           | Путь к файлу логов.                                                                                      |
